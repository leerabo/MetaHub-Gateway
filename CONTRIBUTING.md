# Contributing to MetaHub

Issues and pull requests are welcome. Please describe the user-visible problem, expected behavior, and validation performed.

Before submitting changes:

1. Run the relevant unit tests.
2. Run the frontend lint and production build when frontend code changes.
3. Exercise the changed flow in a browser when it affects forms, dialogs, navigation, authentication, or responsive layout.
4. Confirm that no credentials, customer data, local deployment files, or generated artifacts are included.

Keep public documentation in English first. Add or update the Chinese translation when user-facing behavior changes.
