# PRD-092 平台注册策略与本地注册

## 设计与两轮自审

本设计整理已在同批次编码前审查的注册修订，原始两轮记录为 `MetaHub-public-home-login-design.md` 的“试用修复设计复核一/二”。用户确认配置属于 SaaS 平台，而非企业空间；本地暂不依赖 SMTP，允许自建基础验证码。

第一轮：按运行环境持久化邮件/图形验证开关，只有 PlatformSession 与 platform.operator.manage 可管理。dev 默认免邮件、开启图形验证码；test 保留邮件验证；prod 邮件核验不可关闭。未提供邮件投递服务时，不允许从关闭状态启用邮件。验证码为真实 PNG、设备绑定、3 分钟、最多 5 次尝试、一次消费、速率及总量限制。

第二轮：免邮件流程仅用于 dev 新账号，拒绝邀请接续及账号覆盖，不伪造 account_verifications；记录独立不可变同意事实、Argon2id 凭据和最小化事件。平台注册写操作复核 Cookie 域、CSRF、revision CAS 并原子写审计。前端注册显示密码眼睛、隐私链接、立即 busy、失败可恢复与过期响应清理。

## 提交边界

包含注册策略 API、0146/0153 迁移、本地新账号及注册/平台设置 UI。独立分离组织首屏、创建 Owner 的 0147/0154 授权、消费者及费用功能。公开隐私条款仅用于本地试用，不能作为正式生产法律文本。SMTP 适配、邮件找回与第三方反机器人增强仍需后续开发/配置。
