# MetaHub 可见操作续验：按需填写

## 实际观察

从公开首页登录已有合成验收账号，依照返回空间首页、配置模型服务、账号设置和语言与显示入口操作。
账号安全首屏同时要求多种密码和验证码，未配置验证因子时仍显示无法提交的恢复、信任设备表单。
模型服务首项是已停用服务，仍突出配置密钥，抢占正在使用服务的位置。

## 修订与第一遍自审

账号安全默认只显示状态及三个明确操作入口；一次展开一组输入。
不可用的恢复和设备信任操作显示缺少的前提，不显示无效输入表单。
已发起的恢复挑战和认证器验证必须继续可见，错误始终显示在操作区域外。
启用模型服务优先；已停用服务按需展开，正在处理或有错误的停用项目保持展开。

## 第二遍自审

展开状态只保存在当前控制器，不进入存储；切换操作清理密码、验证码和认证器临时明文。
加载或写入中不切换安全操作，退出和切换栏目清除展开状态。后端校验和授权完全不变。
服务分组不改变记录顺序、不修改服务状态或凭据；读取权限和写入权限继续独立判断。
仅发布前端并复验，保留旧静态包，不迁移试用数据库，不纳入未完成的 S3 文件。
