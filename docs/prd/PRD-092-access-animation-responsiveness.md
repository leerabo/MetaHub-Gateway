# PRD-092 账号首屏动画响应性

## 证据与范围

注册入口已有静态分发优化和真实流程通过，但首次点击偶发超时。2026-09-10 独立匿名页面诊断 `identity-entry-probe-20260910-1788973098777` 显示桌面在动画初始化期间出现 734ms 与 1086ms 主线程长任务，点击创建账号耗时 3359ms；动画模块和 Three.js 下载分别仅 54ms、110ms。对照 `identity-entry-probe-20260910-1788973205110` 仅模拟动画不可用，长任务消失，固定静态回退保留。对照实验只用于定位，不是实际产品验收证据。

手机 CSS 已隐藏动画区域，现有代码仍加载 Three.js 并创建 WebGLRenderer。加载中的账号骨架也会触发动画创建，和认证响应、表单渲染抢占主线程。

## 第一轮自审

账号页继续保留现有视觉和动态场景。只有实际可见、已有真实账号表单且页面可见时才安排动画初始化；隐藏区域不创建 WebGL 上下文。使用浏览器空闲调度将装饰性工作让给表单渲染，离开、页面隐藏或区域隐藏时取消待启动任务并销毁场景。恢复可见状态后可重新加载，不依赖永久全局状态。

## 第二轮自审

动画完全不读取 Cookie、账号、输入值或业务 API。懒加载结果必须再次核验视图状态，离开后不得创建或恢复旧场景。减少动作偏好保留静态视觉且不加载 3D；切换偏好或尺寸后应正确响应。降级或导入失败不妨碍密码眼睛、提交、注册或导航。单测覆盖加载中离开、隐藏到可见、移动布局、减少动作和销毁；浏览器验收仍保留真实动态渲染，不通过禁用动画来冒充通过。
