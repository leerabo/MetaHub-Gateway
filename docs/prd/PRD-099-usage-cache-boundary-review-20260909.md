# PRD-099 用量响应缓存边界修复

日期：2026-09-09。此修复属于 `S2-consumer-usage-accounting-batch-design.md` 已完成两轮自审的用量与导出交付，不替代整条计量 PRD。

## 缺陷与实现

部署后的匿名 `/usage/summary` 返回 401，但缺少 Cache-Control。复查发现 summary、records、导出状态没有统一缓存边界，路由局部设置只覆盖部分 CSV 成功响应。

沿用共享运行时 `_apply_path_cache_control`，为 `/usage` 及 `/usage/` 子路径统一覆盖 `no-store, private`。业务授权、计量、导出列、幂等键、账本和数据库迁移均不改变。

## 实现复核

1. 权限与隐私：成功响应包含内部费用，失败响应涉及授权和任务存在性；全部状态一致禁止缓存。路径按完整根和带斜线前缀匹配，不覆盖 `/usage-other`。
2. 异常与兼容：该函数同时位于普通响应和最外层异常出口，测试必须覆盖 200/401/403/404/422/500；不能只在业务路由成功返回时加头。公共健康页及其他路径不改变。

修复发现于批次部署验收，以上为缺陷实现复核，不冒充新增业务功能的编码前设计。独立测试与敏感审计见同日期 PRD-099 usage-cache 记录。
