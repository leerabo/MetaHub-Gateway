# PRD-147 平台计量恢复页面

共享合同与两轮编码前自审见 `S2-meter-recovery-batch-design.md`。入口只在 SaaS 平台账单页，企业空间不显示或调用恢复能力。

前端读取独立严格 DTO，不向旧账单摘要追加字段。平铺显示状态、待处理计数、源组织、时间和错误。恢复表单绑定原 outbox、序号、尝试次数和摘要；动作初始为空，必须明确确认，服务允许时才显示仅内部成本归档。

恢复期间禁止重复提交；保留同身份同目标的不确定失败幂等键。离页、刷新或身份变化清除意图；迟到读写和会话响应都不能更新新页面/操作者。新增区块标签 14px，复用平台样式和 Lucide 图标。

实现与窄回归已完成；未构建/发布新的 dist。真实 MFA 平台会话下的浏览器闭环及完整发布验收待完成。独立测试和敏感审计见对应 20260909 记录。
