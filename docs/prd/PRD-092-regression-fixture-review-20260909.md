# PRD-092 注册回归夹具修订

## 范围

只修复回归测试输入的时间漂移与客户端分组，不修改生产注册、验证码、反滥用规则、数据库或性能 SLO。前置事实：邀请夹具在 2026-08-24 过期；风险运行时按 IPv4 /24 归一化，注册上限为 300 秒 20 次。性能测试的预热和 20 个采样都落在同一 /24，最后一次应被生产策略拒绝。

## 第一轮编码前自审

- 邀请有效场景的 created/updated 时间使用当前 UTC，expires 使用当前时间加 3 天，不使用遥远固定日期，也不修改系统时钟。
- 四个模拟客户端使用四个不同 /24，预热在第五个网段，仍保留 20 次注册和 20 次验证样本；每客户端各 5 次。
- 独立限流安全测试保留，不能提升阈值、关闭风险预检、删除失败样本或放宽 p95 门槛。

## 第二轮编码前自审

- 本测试仅使用 ASGI 隔离应用，不向真实注册接口分布请求，不更改本地试用策略。
- 注册/验证 p95 仍小于 500ms，滥用计数 p95 仍小于 30ms；修正夹具后若不达标，继续报告真实性能失败。
- 运行完整 PRD-092 API 套件，并在同一 S1 回归运行中覆盖 Workspace 与 Membership；不以单一成功测试冒充批次完成。
