# PRD-094 KEY 表单可读性

## 问题与设计

用户反馈文字过小。真实组织开通后，KEY 创建标签继承 13px，额度标签 11px、输入 12px；姓名/部门表单已为 15/16px。此次只提高 KEY 创建与限制区域字号，不重构全站。

创建标签设为 15px，额度标签和摘要为 14px，文字输入为 16px，额度输入最小高度 40px。保留现有表单网格、移动布局和表格内部滚动，不改变权限、DTO、费用或 KEY 状态。

## 第一轮自审

显式覆盖 input/select 的 font-size，避免 font: inherit 继续继承偏小标签。字体大小不按视口缩放；不通过缩小长文本来隐藏布局问题。只改对应选择器，其他业务页样式留给各自 PRD。

## 第二轮自审

在真实 1280x900 与 390x844 Chromium 中检查文字输入最小字号及页面溢出，checkbox/radio 无文字而不纳入字体断言。检查桌面及手机截图，截图前隐藏一次性 KEY。流程验收仍须包括提交、轮换和停用，不能只凭样式源码认定可用。
