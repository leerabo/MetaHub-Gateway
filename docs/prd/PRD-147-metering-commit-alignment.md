# PRD-147 平台计量提交一致性修复

## 已确认问题

`b52fadd` 从混合工作树提取零上下文 diff 后暂存时，部分计量代码插入到错误位置。当前运行源码正常，但后续 HEAD 的 platform/main.js、platformPageState.js、renderPlatformPage.js 分别出现 import、方法嵌套、模板插值语法错误。2026-09-09 对 HEAD 的三个文件逐个执行 Node 语法检查，均失败。

## 修复范围

沿当前已验证源码修正计量导入、控制器方法、页面加载/清理和事件分发位置。平台注册设置仍为独立增量，不夹带进入本提交；不改后端账务、不重试或分类历史计量事实、不重启已正确运行的页面代码。保留历史提交，追加修复提交。

## 第一轮自审

使用带上下文 diff，并在实际 index 上检查；不能用工作树 lint 代表暂存内容。逐个比对剩余工作树差异，确认只剩注册政策增量。新增命令从 Git index 读取 JS 源码并执行语法检查，不把文件路径解析到工作树。

## 第二轮自审

语法检查不足以证明方法所属控制流正确：将 index 导出为独立副本，运行计量恢复、平台账单、平台访问和合规视图的既有测试，确认页面入口、加载、确认操作及旧功能不受影响。不把集成了未提交功能的本地资产摘要冒充可由该提交独立构建的摘要。
