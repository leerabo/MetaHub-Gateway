# PRD-147 资料与 SDK 页面迁接

本增量覆盖资料读写、保存后的组织会话重入，以及初始化向导的 SDK 示例目的页。原设计与编码前两轮自审按时间记录在 `S1-workspace-profile-navigation-batch-20260910.md`，包括浏览器发现问题后补充的 SDK 后端审查。

第一轮结论：复用现有资源生命周期，不伪造 legacy User；SDK 四个接口显式接入 Workspace 或 Legacy 单一凭据，不修改旧公共守卫和 quickstart 权限边界。

第二轮结论：离页、切组织、角色撤销都取消旧操作；重复下载只发一次请求；下载生成后再次鉴权。元数据连接归事务管理并关闭；Workspace 下载分析事件不伪造 legacy Session，保留真实租户、使用者及 request_id。ZIP 文件清单和文件名仍由服务端固定白名单控制。

资料正文和输入保持 16px，长名称可换行。仅 Owner 显示保存按钮，服务模式等非编辑字段不显示可修改控件。下载示例不等于首次模型调用验收。
