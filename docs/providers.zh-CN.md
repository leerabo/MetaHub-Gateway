# 厂商与模型路由

先登记模型厂商和凭据，再发现模型并建立稳定的内部别名，例如 `fast`、`quality`、`embedding-default`。路由可以设置候选顺序、回退、能力要求、健康度、可用性、安全策略、配额、预算和成本偏好。

系统支持 OpenAI 兼容端点，也提供可扩展的厂商适配器，用于统一认证、模型名称、流式响应、用量和错误处理。可接入 OpenAI、Anthropic、Gemini、Grok、区域厂商和私有端点。模型价格变化后刷新价格数据，成本优先路由会重新评估符合条件的候选模型。

启用生产路由前先测试厂商，并在请求日志中检查实际模型、回退、延迟、Token、估算成本和路由解释。凭据只保存在私有状态存储中，按项目或应用范围创建虚拟 KEY，绝不提交到 Git。
