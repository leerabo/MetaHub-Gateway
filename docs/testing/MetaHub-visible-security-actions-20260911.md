## 方法与范围

使用 computer-use 技能推荐的浏览器接口，观察截图后沿可见入口操作。
本轮使用既有合成验收账号及“体验验收组织 0910”，未操作用户业务组织。
浏览器检查登录、返回空间首页、模型服务、账号设置、语言与显示、员工与 KEY。
选择栏目与展开表单不计为提交业务动作；没有创建账号、员工、KEY 或安全凭据，没有付费模型调用。

## 新发现与处理

- U43：账号安全同时铺开多组密码和验证码表单。改为状态优先，按明确动作展开一组输入。
- U44：没有恢复和设备信任条件，仍显示无法提交的表单。改为显示缺少的前提。
- U45：手机空账号展示三个空统计，占据大量空间。没有配置时省略空统计。
- U46：停用服务先于启用服务出现，干扰接入选择。启用服务在前，停用服务折叠；正在处理或有错误的项目保持可见。
- 收起安全操作清理临时输入和认证器明文；收起停用服务整组也清理未保存的密码输入，并关闭内部密钥面板。

## 浏览器结果

- 公开首页登录合成账号成功，恢复上次工作页；返回空间首页后，四步接入和下一步可见。
- 账号设置没有误显示登录表单；语言与显示加载后有语言选择及保存入口，返回组织保留登录。
- 员工页面展开添加表单只有姓名与可选部门，无邮箱、密码及注册要求。没有再次提交创建。
- 安全页默认三个操作入口、零可见输入；展开验证方式后切换安全密钥，表单保持展开。
- 输入无效合成草稿后切换受信设备，再返回验证方式，实际 DOM 确认值为空且类型仍为 password。
- 缺少认证器时没有信任设备表单；缺少恢复条件时没有恢复密码表单。
- 最终版本 390x844 手机闭合和展开状态的文档宽度与可用视口均为 375px；截图无横向溢出或控件重叠。
- 1440x900 桌面展开验证表单及返回入口经过截图复核。没有向任何安全操作提交密码。
- 停用验收服务在启用服务之后；读取错误时自动展开显示重试入口，重试成功后默认收起。
- 在停用服务的厂家 KEY 框输入无效合成草稿，收起整组后，实际 DOM 中非空密码框与展开密钥面板均为 0。
- 模型服务页的 390x844 手机文档宽度与可用视口均为 375px，列表文字与按钮没有重叠。
- 恢复默认视口后实际点击登出，经过退出提示返回新版公开首页；合成验收账号未保持登录。
