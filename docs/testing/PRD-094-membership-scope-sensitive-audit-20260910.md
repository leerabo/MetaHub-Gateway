# PRD-094 成员隔离敏感审计

迁移只改变状态传播条件及对应治理摘要，不复制密码、Token、邮件或密钥；不修改现存账号状态。Owner 的权限限定在自身组织，不引入平台提权或跨组织恢复能力。

实际 API 测试使用随机本地账号和 Cookie，断言只记录测试状态，不打印凭据。第二组织继续可用、原组织同形拒绝、全局停用不能被组织恢复均有 SQLite 与 PostgreSQL 证据。迁移内使用 tenant_id + legacy_user_id 复合匹配，不依赖可能跨租户重复的单一 user_id。

原生数据库运行报告确认既有数据库清单保留。在线数据库尚未应用此次迁移，不把隔离验证写成已经发布。
