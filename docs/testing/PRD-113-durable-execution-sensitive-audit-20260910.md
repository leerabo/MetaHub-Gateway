# PRD-113 持久执行敏感审计

日期：2026-09-10。范围仅本次执行器、客户端协议、基线门禁和部署配置。

## 边界

- 请求不允许 URL、凭据路径、命令或脚本。目标由部署白名单确定，只接受私网或环回 IP origin。
- IPv4-mapped IPv6 按实际 IPv4 判断，拒绝元数据地址、公网地址、接口区域标识和控制字符。
- HTTP 禁用环境代理和重定向。响应正文只流式计数，不进入账本或报告。
- 合成身份与资源探针使用不同凭据文件。文件只在执行器内读取，配置变化由摘要识别。
- 存储仅有固定参数、摘要、安全状态、计数、直方图和资源聚合。没有客户账号、KEY 或正文。
- 探针返回进程代次摘要和资源值，不返回 PID、命令行、环境变量、地址或句柄明细。
- API 需要内部 Bearer 和短期签名。查询与取消验证对象、摘要和时间，响应包括拒绝状态均 no-store。
- 取消可先于提交，停止事实在同一个状态库持久化。重启不会重放已停止或中断的执行。
- 容器以 65532 运行，状态卷独立，不挂载 Control 数据库、Docker socket 或客户配置。

## 验证范围

实际请求只到测试创建的环回目标及其资源探针，没有调用试用 Gateway、模型厂家或支付服务。
测试使用明确的合成凭据，并扫描落库内容，确认凭据、响应测试标记、Authorization 和目标 URL 未落库。
本轮没有读取用户提供的模型 KEY，没有重置试用账号，没有更改 5173/8001 运行进程或数据库。
禁止把协议 fixture 中的 measured 标签当作真实容量证据，基线门禁测试仅证明状态机和持久行为。
最终 109 项执行器/协议/部署结构与 12 项数据库 API 测试通过；具体 XML 和修正过程见同日专项记录。

## 剩余风险

部署配置属于受信管理员输入，资源探针目前只证明单目标进程而不是全服务集群。
合成 subject_code 与不同凭据不等同于 Gateway 已证实的独立租户。
已停止只表示 runner 不再产生/等待请求，不表示目标下游副作用已撤销或故障已恢复。
Control 持久等待、取消传递和故障恢复仍是启用真实执行的前置条件；Docker 运行隔离尚未实测。
