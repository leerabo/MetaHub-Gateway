# MetaHub 注册页渐进加载复验

日期：2026-09-11。

## 用户路径

从公开首页点击“创建账号”，只根据页面可见文案操作。首次冷加载时，注册策略接口可能需要数秒；原实现会锁住整张表单并显示“正在加载”。这会让用户误以为页面没有响应，也无法先填写邮箱和显示名称。

## 本轮修订

- 注册表单先展示并允许填写邮箱、显示名称、密码和确认密码。
- 策略加载期间只禁用提交，并显示“正在准备本地注册验证”。
- 策略返回后，只有启用基础人机验证时才显示图形验证码。
- 策略异步返回不会清空用户已经填写的邮箱和显示名称；密码和验证码不进入控制器草稿状态。
- 策略读取失败保留可读表单和明确错误，提交保持禁用，用户可重新进入注册页恢复。

- Computer Use：公开首页 → 创建账号；注册页首屏字段可操作，密码眼睛、隐私条款和图形验证码均可发现。
- 前端 identity 专项：36/36 通过。
- 前端完整回归：2111/2111 通过。
- `npm run lint`：通过。
- `npm run build`：生产资源 291 个，构建通过。
