# PRD-093 创建组织跳转敏感审计

范围：创建组织后的前端跳转、独立单测、两份构建摘要及本次设计和测试记录。最终暂存扫描结果需按实际 index 核对。

- 不新增注册凭据、账号密码、供应商 KEY 或浏览器存储项。
- 不跳过 WorkspaceSession、成员与导航的权限 revision/fingerprint 校验。
- 跳转必须属于当前操作代次和本次创建的组织；退出、切换、迟到响应不能恢复旧组织。
- 仅本次创建且确有跳转回调时停止附加面板预加载，其他账号安全页面仍按原流程读取。
- Owner 不获得 Platform 管理权；注册链接、隐私条款和验证码策略不在本次改动范围。
- 发布保留旧构建与旧摘要以供恢复，不改数据库、账号、Cookie 密钥或用户 `.env`。

本审计不代表对全部未提交 S2 文件或整个仓库的安全背书。

最终暂存范围共 7 个文件，限定名单逐项匹配，已完成供应商 KEY、私钥、云访问密钥和 JWT 特征扫描，零命中；两个暂存 JavaScript 文件语法检查通过。机器记录：`.artifacts/g6-security-20260907/prd093-entry-index-audit-20260909.json`。只提交该独立范围，工作树的 S2 构建摘要不混入本提交。
