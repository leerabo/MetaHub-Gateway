# 本地试用注册与平台验证设置

日期：2026-09-09。对应用户试用反馈：字号、服务状态、密码显示、隐私条款、注册提交和基础人机验证。

## 交付边界

- 配置位于 SaaS 平台 `/platform.html#operators` 的“注册验证设置”，不是企业空间。只有 `platform.operator.manage` 可读写；接口为 `/platform/registration-policy`，要求 PlatformSession，写入另校验 Origin、CSRF 与修订号。Workspace/Support 凭据混用被拒绝，变更写入平台审计。
- 开发环境默认邮件验证关闭、基础图形验证码开启；免邮件注册只允许 `dev`。生产环境不允许关闭邮件核验。SMTP 尚未实现或接入，不能把安装服务器 SMTP 等同于应用已能发送邮件。
- 基础验证码是服务端生成 PNG，5 位数字、3 分钟有效期、最多 5 次尝试、一次消费、设备绑定、限流及有界过期清理。它不等同于专业反机器人服务。
- 免邮件注册不覆盖账号、不生成 `account_verifications`、不消费邀请。新账号保留独立同意记录、Argon2id 密码和 `local_unverified_registration` 审计。
- 隐私说明为独立可访问的 `/privacy.html`，版本 `privacy-local-2026-09-09`，只适用于本地开发试用；正式上线仍需运营方发布正式隐私条款。未接邮件服务时，邮件找回密码不可用。
