# PRD-099 计量恢复敏感审计

- 平台 Cookie + Origin + CSRF；混合 Bearer/Workspace/Support 拒绝。写服务重新认证并校验 platform.billing.adjust，读取权限为 platform.billing.read。
- 所有客户端 ID、版本和哈希只绑定当前失败头；组织和源事实从数据库恢复。追加审计与检查点 CAS 同事务；不写内部账本或历史权益。
- response DTO 只含状态、计数、组织 ID、序号、枚举错误和恢复摘要，无员工姓名、邮箱、模型凭据或请求正文。源摘要是不可逆哈希，异常错误码有明确允许列表。
- 数量、源归属和历史订阅同时有服务与 DB trigger 检查；SQL 参数化。恢复事实不能更新或删除，回滚不能删除已有处理证据。
- 已检查本增量源码/测试与证据；测试密钥均为本地固定测试值，不包含用户提供的上游 KEY。提交只纳入本域文件，不纳入 `.tmp`、`.data`、日志、数据库或完整 dirty worktree。
- 真实 MFA 的 API 全链路已由 `meter-real-auth-r2-20260909.xml` 补证：使用公开 API 建立身份、角色和支持会话，只控制隔离配置与时间。没有绕过鉴权、直接插入平台身份或改动用户账号；调用模型服务次数为 0。
- 新测试只引用既有本地测试凭据，不嵌入用户 KEY；证据不输出 Cookie、MFA seed、员工资料或请求正文。r1 失败回显的是固定测试源码与脱敏错误，不含实际 TOTP seed。
- 未完成的安全证据：认证浏览器操作、生产环境压力下撤权与归档/订阅并发完整矩阵、真实历史分类决定。不能以隔离 ASGI 测试代替这些事项。
