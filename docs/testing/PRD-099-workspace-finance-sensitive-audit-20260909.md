# PRD-099 组织财务增量敏感审计

金额仍以整数微元/十进制字符串传输和累计，不把估计费用当应收，不隐式合并币种。组织、KEY、项目、应用归属从服务端恢复，预留探测复用共享结构化表 API。

预算写入、block 释放和审计同事务；撤权或审计故障时回滚。预算列表、状态、成功与异常响应均 no-store。角色、CSRF 与撤权测试见独立测试记录。

本地 HTTP 使用隔离测试组织，未读写用户 KEY 或 Provider 凭据，未调用付费模型。报告仅记录状态、组织测试 ID、时间与计数，不含密码、Cookie 或 KEY 明文。生产体量、跨系统对账与共享 DbError traceback 问题未关闭。
