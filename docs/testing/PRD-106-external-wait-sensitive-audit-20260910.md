# PRD-106 外部等待敏感审计

日期：2026-09-10。范围限本次 PRD-106 源码、迁移、DTO、前端及专项测试。

- API 仍以 PlatformSession、平台权限、CSRF、CAS 和幂等命令为边界；未复用企业任务事实或企业授权。
- 外部恢复 handler 仅编译期注册，无客户端模块、命令、目标 URL 或脚本入口。
- 续接参数使用 KMS envelope，AAD 绑定原 job/type 与 external-v1 域；数据库保存随机令牌 HMAC。
- 原 job/attempt 与等待归属不可变，旧恢复者在外层 fence、代次、令牌和数据库时间校验后仍需提交前复核。
- 解密完成后、调用外部 handler 前再次检查恢复租约，KMS 慢响应不能让过期恢复者发起执行。
- 平台安全摘要仅含状态、计数和时间。前端严格拒绝 lease_token、continuation_envelope 等扩展。
- 未知异常只保留 platform_job.external_unavailable 固定码，不保存原始异常、请求、响应或签名正文。
- 停止尚未确认时不能普通终结或重试；取消优先且事务回滚业务效果，不能生成虚假健康结果。
- 测试只使用随机测试 secret、合成 marker 和隔离数据库。PostgreSQL 临时 trust 实例只监听环回，
  没有生产数据或模型凭据，最终已停止。未修改已发布试用进程、数据库或资产。
- 本次提交明确排除原先的账号页面改动以及 .tmp/.artifacts 运行数据，仅保留可重跑源码与记录。

剩余风险：PRD-113 领域适配尚未完成，外部 handler 的停止确认仍需真实 runner 证据；
配置错误、不可解密续接与长期外部故障只保留待恢复事实，不能自动宣布远端安全。
实际多租户公平、72 小时轨迹、旧新版本混跑、全浏览器及完整安全回归留在 S3 批次门禁。
