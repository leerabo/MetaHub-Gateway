# PRD-147 同源入口敏感审计

- Control 地址仅取当前页面 origin，loopback 开发站点取当前协议和主机的 8001 端口；不读取任意查询参数、Storage、员工字段或服务端业务 DTO 作为凭据目的地。
- 保留 workspaceCookieApiOrigin，不修改 Cookie 域、SameSite、CSRF 或后端身份边界。组织 Owner 仍不获得平台权限，员工 KEY 不能访问消费者管理接口。
- 源码无新增凭据。真实浏览器使用随机测试密码、随机会话与 KEY；测试只为自有隔离验证码固定字符随机源，未修改用户运行环境。
- 截图在密码填写前或 KEY 隐藏后生成，失败截图遮挡全部输入和一次性秘密；报告仅保存状态、页面路径、计数，不保存 Cookie、认证请求或响应正文。
- 本记录对应入口修复，不把整个脏工作树、未提交的注册政策或消费者实现宣称为已独立提交。暂存内容的禁止路径与高置信度密钥扫描另存机器证据。

剩余：HTTP 同源浏览器不能替代公网 TLS/代理配置审查；Gateway 是单独的无 Cookie API 地址合同，本增量不猜测公网端点。
