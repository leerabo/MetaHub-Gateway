# PRD-092 账号动画敏感审计

动画模块只处理可见性、布局、动作偏好和密码显示控件；没有读取 Cookie、账号、输入内容、Storage 或业务接口，没有增加网络服务地址。离开、隐藏、销毁及异步导入返回都检查当前生命周期，防止恢复旧视图。

浏览器验收使用独立数据库、随机管理员凭据、局部确定性图形验证码和仅限测试来源的浏览器请求；不读取试用 `.env`，不修改用户会话或在线数据。Provider 调用数为 0。Gateway 通过空反馈请求分别验证有效、旧版和停用 KEY，不产生模型费用。

报告不保存 Cookie、KEY、密码、请求正文或原始异常正文。新连接诊断仅匹配固定错误词；失败截图遮蔽输入及一次性密钥。成功截图取自空注册表单或已关闭一次性密钥后的页面。KEY 的管理接口拒绝、轮换失效、停用阻断及浏览器 Storage 无明文断言均通过。姓名和部门只使用合成测试值。

独立构建与本地聚合发布分离，聚合包只允许替换 `src/features/identity/accessExperience.js`，以摘要验证其他已发布资产不变。在线数据、原发布包和已有失败证据均保留。本记录不替代未完成 PRD 的敏感审计。
