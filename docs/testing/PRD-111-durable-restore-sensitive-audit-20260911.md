# PRD-111 持久恢复敏感审计

日期：2026-09-11。范围与测试记录一致。

- journal 仅保存有界执行身份、请求/目标/数据摘要、后端/OID、状态与无行值的表指纹；
  不保存数据库连接串、密钥、客户文本或子进程 stderr/stdout。
- pg_restore 使用必要的内存环境传递连接凭据，输出指向 DEVNULL，结束后清空环境副本。
  停止错误与损坏 JSON 通过固定错误码报告，不透出 Pydantic 输入转储。
- 恢复文件/数据库含合成测试数据，保留在测试专属位置；正常执行所用 state 目录要求
  部署方使用私有存储和受限服务身份，真实备份/恢复产物不能作为公开测试附件发布。
- 新增回归校验敏感测试标记不出现在私有 journal 的结果与异常文本中。
- 对本轮 final/schema 两个测试目录中的 `.log`、`.json`、`.xml` 搜索已知合成敏感标记，
  无命中；进程检查没有对应测试 PostgreSQL 残留。
- 本轮未读取仓库 `.env`、用户提供的真实模型 KEY、员工数据或试用数据库。
- 本审计不代表远端恢复服务认证、密钥轮换、跨区 KMS 或生产恢复权限已经验收。
