# PRD-113 持久执行与基线质量

日期：2026-09-10。状态：本阶段实现与专项测试通过。PRD-113 整体仍未完成。

## 范围

原始要求来自 `01_PRD总表!A25:Y25`。按表格技能只读核对 S3 行，未修改原计划。
批次设计及两轮编码前自审：`docs/prd/S3-measured-runner-execution-20260910.md`。

- 独立 SQLite 执行账本、排队、参数幂等、generation、取消与 kill 持久化。
- 单进程 OS 锁；重启将旧执行记为 interrupted，不重复施压。
- 实际 HTTP 测量和独立目标进程资源探针，聚合有界，不保存响应正文。
- POST submit 可返回 202；签名 status/cancel 返回绑定对象及执行摘要的闭合状态。
- permit 是最晚启动授权。排队或初始探针期间过期均不发负载，新签名不能复活终态。
- 取消先到时落库停止记录，迟到提交不会启动。停止范围明确为 runner 自身请求。
- Control 客户端新增单次 submit/status/cancel 协议，验证状态码、对象、摘要及嵌套结果。
- 首条基线加入延迟、错误率、成功吞吐、公平性和受控降级门禁；坏结果不能清除旧阻断。
- 可选 Compose 叠加配置使用独立状态卷和只读配置目录，默认配置不启用真实负载。
