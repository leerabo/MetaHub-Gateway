## 范围

- 同事务初始化领域和外部等待；网络调用在交接事务提交以后发生。
- 原 permit 未确认提交重放、查询续签、跨普通执行期限等待、超过 20 次观察。
- 提交前/过程中取消、实际 runner tombstone、kill 的持久意图与停止确认。
- 超时且 runner 不可达时保留等待，迟到成功不能建立取消任务的基线。
- 过期恢复者、领域提交异常回滚、启动超时和未启动任务终态投影。
- 同步入口拒绝真实外部提交；现有容量 API、权限、审批、质量门禁回归。
