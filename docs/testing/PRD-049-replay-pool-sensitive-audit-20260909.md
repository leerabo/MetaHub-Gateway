# PRD-049 独立写连接池敏感审计

日期：2026-09-09。范围：反馈写入 opt-in 连接池、关联测试、分阶段诊断和本地发布证据。

- 只有原反馈写权限依赖与业务 worker 进入新 scope；默认调用、内存 SQLite 和原生
  PostgreSQL 连接路径不变。物理连接独占到 close，关闭后旧 facade 失效。
- 重用前沿用有界池的 rollback 和状态重置。线程取消不会交由 HTTP teardown 提前
  归还 worker 连接；没有延长授权、删除终态校验或放宽 250ms 汇总预算。
- 两轮真实诊断与发布回放只重用已存在操作和反馈，不提交新模型调用。日志和报告不含
  SQL、业务正文、Cookie、原反馈标识或密钥；测试命令不打印凭据。
- 新增时间边界断言保留左闭右开语义，原先跨秒假设失败与错误 cwd 的 setup 原件保留。
  不把测试断言修正解释为统计生产规则变更。
- 发布 helper 在停止前核对固定 PID、启动时间、执行路径、模块和 8001 监听，记录旧
  进程已发生的丢弃及后端失败。没有重启 Gateway/Console，也没有重置数据库水位。
- 实际回放 8 次保持同一反馈，自己的会话退出 200；13 组账务事实摘要未变。受保护源
  baseline 与可复用迁移输入的 SHA-256 均未变，原失败 outbox 和 pending 行保留。
- 首次启动观测失败、历史间歇错误、长期稳定性和财务闭环未完成项保持可见。
