# PRD-147 平台计量恢复页面敏感审计

前端的显示权限不代替服务鉴权。请求使用平台 Cookie、CSRF、no-store 和独立幂等键，不保存或发送后台登录 Bearer，也不接收任意 tenant 参数。

旧表单必须与当前四项源版本相等；无权限、无确认、无归属、旧页面或重复提交不发请求。归档选项按服务端当前允许状态裁剪，服务仍再次校验。会话响应在代次校验之后才写入状态，离页清理恢复意图。

所有 DTO 字符串在 DOM 转义；错误显示仅固定枚举说明，表单无金额或客户业务正文。隔离截图无真实用户或上游密钥。恢复改动与未提交的平台注册策略通过逐块暂存分开，不将历史未提交功能混进本 PRD。

本地发布后实际 HTTP 校验 289 个资源及摘要；未登录计量恢复 GET 返回 401。进程重启前逐项核对 PID、启动时间、可执行文件、模块和监听端口，只替换 Control/Frontend；数据库仅新增 0149。真实历史财务事实保持原哈希，未调用恢复写接口。备份含真实数据，留在忽略的 `.data` 内，不纳入提交或在聊天展示内容。
