# PRD-111 恢复点绑定敏感审计

日期：2026-09-10。状态：本实施单元审查完成；完整 PRD-111 安全门禁未完成。

## 数据与授权

- 新表只存内部 run/job/recovery/region ID、epoch、schema、时间和摘要。
  object_key 仅在后端从原备份读取，新绑定保存其 SHA-256；不新增连接串、凭据或客户正文列。
- 新代码不输出原始 backup 行，不增加日志、事件 payload 或公开数据字段；沿用统一 ApiError。
- 平台级完整备份不能由工作空间备份代替；绑定与审批、入队在同一事务，不新增用户可选 owner。
- 所有 Worker 效果包括失败回写均核对当前 job，避免错误 payload 影响另一个 run。
- 新 PostgreSQL trigger 函数显式 `pg_catalog, public, pg_temp`，防止恢复时空 search_path 失效。
- 源区域审批采用行锁。绑定、关联 job、开始时间不可替换；旧任务不伪造回填恢复点。

## 测试与环境

- 夹具清除继承 METAHUB 配置、切换临时工作目录，使用固定合成凭据和绝对迁移路径。
- 原生集群绑定 127.0.0.1；测试数据库由当前运行随机命名创建，schema 重置仅发生在该数据库。
- 失败原生集群按实际 PID 和 data 路径核对后清理进程，没有删除保留 `.tmp` 文件或用户数据。
- 专项测试不访问外部 Provider、Codex 配置、真实密钥或试用库；不执行付费请求。
- 最终检查仅对本项文件和测试 XML 扫描，不把仓库历史敏感内容打印到工具输出。

## 残余风险

绑定证明的是恢复输入身份，不证明恢复发生过。当前 metadata-only 阶段仍未连接实际 runner，
其成功路径必须在下一个实施单元去除；本修改不发布到试用运行时。
完整云端灾备验收、生产容量与 72 小时稳定性没有由本专项测试证明。

## 验证结论

84 条自动化测试通过，SQLite 完整迁移链的正式版本保护回滚/重放通过。
本轮故障进程的退出码已核验为终态，Windows 遗留对象和端口记录仍保留，未扩大到系统重启。
最终测试集群均正常关闭。本轮仅提交设计、服务/Worker 绑定逻辑、新增迁移和相关测试/审计，
不提交试用 UI、运行数据库、临时证据、供应商凭据或环境配置。
