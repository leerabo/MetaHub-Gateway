# PRD-092 平台注册策略敏感审计

策略接口只接受 PlatformSession，拒绝 Workspace/Support 凭据混用，修改额外校验 Origin、平台 CSRF、管理权限和版本；组织 Owner 无权配置。公开策略不含邮箱、账号目录、投递秘密或平台身份。

验证码答案以独立域 HMAC 保存，设备绑定，不记录明文答案。dev 注册仅产生新 GlobalAccount、Argon2id 凭据及不可变本地同意记录；不生成邮箱验证事实或 Workspace/Membership。生产免邮件入口和邀请均拒绝。重复账号错误在本地开发范围内可区分，不能声称它符合正式邮件注册的完整同形防枚举合同。

前端密码可显示后仍按 autocomplete=new-password 清除；注册与验证码响应不进入 Storage。API 日志、事件不写密码、验证码答案或完整密钥。测试中的固定密码和例子域名仅是隔离夹具，未使用用户第三方 KEY。

独立暂存排除组织、消费者及财务变更；生产资产摘要按 index 内容计算，不读取运行 .env。最终禁止路径和高置信度凭据扫描会针对实际提交内容记录，不能把它当作全仓最终敏感验收。
