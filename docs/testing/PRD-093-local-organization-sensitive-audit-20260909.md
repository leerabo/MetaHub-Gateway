# PRD-093 本地组织创建敏感审计

只有当前 dev 注册政策关闭邮件验证且账号有本地同意来源时允许免邮件创建。数据库授权绑定 workspace_id/tenant_id/account_id/registration_id/policy_revision，不可变；prod/test、无同意来源、邮件已启用都拒绝，不给账号补邮箱证明。Owner 仍是组织身份，不产生平台操作员。

用户名称在 UI 转义，不加入密码、同意或幂等敏感正文；创建回滚保持组织、Owner、claim 与授权事实一致。前端不读取客户端 tenant 参数授予权限，目录失败不伪装成新账号。禁用重复提交与草稿恢复不扩大服务端权限。

迁移测试只使用自己创建的副本，经正式 expected_version/数据库事务执行 down；不会直接删除迁移历史，不更改用户 .data 库或旧测试证据。本次暂存高置信度凭据/禁止路径审查针对实际 index，和运行包/全仓审计分开记录。
