# PRD-092 账号动画响应性测试

## 范围与结果

本次只修复账号表单与装饰动画的初始化竞争，不改变注册、邮件验证、人机验证策略或组织权限。设计及两轮自审见 `docs/prd/PRD-092-access-animation-responsiveness.md`。

- 工作区与独立暂存区导出各 44 项前端测试通过，包含 6 项动画生命周期测试。证据：`.artifacts/g6-security-20260907/s1-access-animation-unit-20260910.xml`、`s1-access-animation-index-unit-20260910.xml`。
- 独立导出树 `22c695624d950c1f988b573255bad335153c1780` 构建通过，271 个模块、289 个资产。资产摘要 `30532f7024387597326dbe030cbc4392a81bc8bab983482c4cabc8b565b33843`。
- 真实 HTTP 逐项校验 289 个构建资产。桌面 1280 与手机 390 均通过注册、组织创建、使用者创建、KEY 签发、轮换、停用和管理权限拒绝。证据：`.artifacts/s1-browser-jp9dqofw/acceptance.json`。
- 桌面可见画布 2593 种颜色，间隔截图有 8766 个明显变化像素；暂停/播放按钮状态通过。手机不存在隐藏 WebGL 画布。6 个页面布局检查均无横向溢出，输入字体至少 16px；已人工检查两端注册截图。
- 新增 4 名使用者及 4 把关联 KEY，只因两名管理员和两个组织新增 2 个 GlobalAccount、2 个 User、2 个 Membership。员工没有登录账号。无页面异常、无外部浏览器请求，测试服务已停止。

## 保留失败与限制

- `.artifacts/s1-browser-80e3jpk7` 是画布负坐标导致截图裁剪错误，已改为截取视口与画布的可见交集，非降低像素断言。
- `.artifacts/s1-browser-xuvaz2rz` 的失败点实际是脚本读取 `/workspace/session`，不是等待使用者表单；截图已显示该表单。原记录未保留连接错误类型，根因未确认。新增固定白名单错误分类后，同一构建、不修改超时阈值的复跑通过，不将其描述为已定位的产品问题。
- 本次验收是 Chromium 的增量注册链路，不替代 Excel 的全部浏览器、DPR、SSO、账务、压力或长稳验收。计时含填写与截图，不用作 API p95 指标。
