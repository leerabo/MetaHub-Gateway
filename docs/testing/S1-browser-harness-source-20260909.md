## 设计和两轮自审

范围：PRD-092..094 共用真实浏览器验收脚本。允许选择当前工作树或工作区 `.tmp` 内的明确源码导出；生产模式只能读取所选导出的 `console-web/dist`。隔离库、临时浏览器资料及结果始终属于主工作区，不读取试用 `.env`，不调用收费模型。

第一轮自审：源码路径必须实际存在且位于允许目录，导入的三个后端模块须来自所选源码。生产模式配置必须是精确布尔文本。逐个 HTTP 请求核对构建清单的资源内容哈希，不能用源码测试结果代替实际构建验证。

第二轮自审：公开静态资源应独立分发，不应遍历业务 API 路由表。仅 `/src`、构建清单列出的根级 HTML 和首页进入静态处理；业务、平台、未知路径均进入完整 Control。不得通过伪造 Session、模拟授权响应或加长等待时限使验收变绿。日志仅保留状态、耗时、脚本位置和无查询参数的路径，不保存 Cookie、请求正文或 KEY。线程栈只含代码位置，不含局部变量。
