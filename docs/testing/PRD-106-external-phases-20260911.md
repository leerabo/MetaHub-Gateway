## 主要断言

恢复阶段提交后根 job/attempt 继续 running，等待记录与 continuation 不变；观察进程崩溃
接管后，相同 effect 不重做业务变更，下一阶段可继续，根 attempt 始终为 1。
相同 key 不同摘要拒绝；回调异常/崩溃、租约失效、总截止时间跨越、外层 fence 失效全部回滚。
取消或超时拒绝新阶段，但不将未停止外部执行提前终结。普通和外部阶段的幂等命中也重新
检查截止时间。真实 PostgreSQL 并发提交只产生一个 effect，pg_sleep 跨越租约后写入回滚。

首两轮新测试各有 1 个断言预期错误：普通任务过期抛任务超时，而非观察租约失效；普通任务
fixture 也没有外部 start 插入的那一行。已按现有语义明确区分，无实现放宽或跳过测试。

这些时钟边界测试不是 72 小时实测，不是性能或容灾成功证据。未修改或重启 5173/8001。
