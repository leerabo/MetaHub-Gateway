生产构建曾因接入页变更后的资产摘要漂移失败。现已同步前端与 Control 的发布清单，保留构建时逐资产摘要校验。Control 同时重启加载新的清单，继续沿用本地关闭后台调度器的配置；这不是正式环境的验收配置。

本轮版本核对审查区分源码、构建产物、实际 HTTP 三个证据来源。凭据及功能边界审查确认只进行匿名运行检查，跨协议计费使用合成员工与本地模拟上游，不改写用户员工数据、不调用付费厂家模型。
