# PRD-094 KEY 表单字号敏感审计

修改限定 CSS 中 KEY 创建及额度表单的字号、最小高度，不触及凭据、身份、路由或账务。独立暂存时排除同文件里的使用者目录、用量和财务样式，避免其他功能混入本提交。

浏览器验收对一次性 KEY 只在测试内存读取；截图前关闭明文，未写入 Storage。生成的报告不含认证正文，失败截图遮挡输入与秘密。0 次外部模型调用，未读取用户供应商凭据。隔离测试服务与浏览器已退出，成功副本数据库已删除，真实试用库和用户会话保持原状。

本记录只覆盖字号增量及所引用的隔离浏览器证据；使用者 DTO、跨租户权限、不可变归属和 Gateway 停用的审计另见 `PRD-094-consumers-sensitive-audit-20260909.md`。
