# PRD-113 外部等待联动敏感审计

范围：Control 容量续接参数、签名提交/查询/取消、领域终态、迁移和前端停止状态。

- 原始 permit claims 只含封闭目录 code、合成规模、时限和对象绑定，不含 URL、路径、
  模型凭据、Prompt、Response 或租户商业明细。续接内容由 PRD-106 绑定 job/type 加密。
- 续签只改变 status/cancel 的时间字段，不接受浏览器提交新执行摘要或任意网络目标。
- 外部恢复上下文在请求前、结果回写和事务提交前验证所有权；领域对象必须属于原 job。
- 网络异常与未知恢复异常只持久化固定原因码，不向事件或 DTO 写入原始异常、HTTP 正文。
- 取消/超时不能生成基线或清除旧发布阻断。前端停止状态只使用既有安全 DTO 字段，
  不暴露 continuation、token HMAC、签名或 worker 内部信息。
- SQL 终态投影只使用原任务已有状态与安全原因。失败摘要不是测量结果，不用其生成基线。
- 测试使用独立数据库、明确的协议夹具及独立 runner 本地目标，不读取试用模型密钥。
- 当前试用发布和数据库未改动；PostgreSQL 并发执行、跨域回归和完整扫描仍属 S3 批次门禁。

本审计仅覆盖本次变更，不替代整个 S3 安全验收或外部故障撤销证明。
