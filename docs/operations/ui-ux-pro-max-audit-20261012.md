# MetaHub UI/UX Pro Max audit

本轮重构以当前产品的三类使用场景为边界：公开入口、组织后台、SaaS 平台后台。业务接口、权限判断和数据结构保持不变，展示层负责把接口事实组织成可完成的任务。

## 设计决定

- 方向：技术型 B2B 控制面，深海蓝底、半透明玻璃表面、青色交互强调；使用轻量渐变光晕和模糊，不堆叠装饰性大卡片。
- 字体：系统无衬线字体（Inter、Segoe UI、Microsoft YaHei、PingFang SC），正文 14–16px，页面标题 24–32px。
- 间距：4px 基础单位，常用 8/12/16/24px；按钮和输入框最小高度 40px。
- 圆角：控件 10px，面板 16px，弹框 22px；阴影只用于层级分离，表面同时使用细边框和 16–24px 模糊。
- 信息层级：侧栏只显示目录；页面首屏依次放状态摘要、一个主要动作、列表或明细；低频配置使用对话框/折叠区。
- 响应式：900px 收起为单列，560px 进一步压缩标题和操作区；表格只允许在自身容器内滚动，页面不横向溢出。

## 已实施的共性改造

1. 删除组织侧栏入口中的重复说明，保留分组和缩进层级。
2. 新增 `design-system.css`，统一两个后台的玻璃表面、颜色、间距、控件、表格、弹框、焦点和断点规则。
3. 首页新增独立 `public-design.css`，把首屏改为产品价值 + 网关状态的双栏布局。
4. 组织概览减少解释性脚注，常用管理改为“下一步”，让首屏承担决策而非说明书。
5. 所有后台表格和弹框限制在容器内，避免页面被宽表格撑开。

## 本轮验证结果

- 身份页：在 1280、768、375px 真实浏览器截图检查；输入焦点、密码显示按钮和错误容器保持可操作，三个宽度均无横向溢出。
- 控制台与平台业务页：统一玻璃表面、按钮、输入、表格、弹框和移动断点；代码层完成组件渲染与静态布局检查。
- 响应式：桌面表格在自身容器内滚动；900px 以下转为单列，620px 以下压缩表单，430px 以下单列；页面根节点隐藏横向溢出，避免整页出现底部滚动条。
