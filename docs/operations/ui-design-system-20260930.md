# MetaHub UI design system

## 2026-09-30 全站重设计

本轮不是局部换色，而是把公共首页、账号入口和控制台重新收敛到同一套 B2B AI Gateway 视觉语言：深墨绿导航轨、暖灰工作区、白色内容面、青绿色主操作色，状态色仅用于表达状态。控制台从“整页大卡片”改为固定工作区导航、页头上下文带、操作区和数据工作面；Provider、路由、成员、用量、预算和私有 Gateway 都按任务拆分，卡片只用于需要框定的重复项、工具和弹框，避免白卡套白卡。公共首页改为左右分区的产品入口，登录页改为深色品牌侧栏与聚焦表单，移动端保留同一层级和动作顺序。

- Typography：系统无衬线字体栈，标题 780 weight、正文 14-16px、辅助文字 12-13px，字距保持 0。
- Color：`#17332c` 墨绿、`#f3f5f2` 暖灰背景、`#ffffff` 内容面、`#087f6b` 主操作、`#d8e0dc` 分隔线、`#208454` 成功、`#a26716` 警告、`#bd443d` 错误。
- Spacing：4px 基数（4/8/12/16/20/24/28/32），不再引入页面级随机间距。
- Radius：控件 6px、面板 10px、弹框 12px；阴影只保留弹框和导航轨的低层级浮起效果。
- Responsive：820px 以下导航转为单列可折叠区域；600px 以下首页和登录页使用单列首屏，按钮和输入保持触摸尺寸。

实现位于 `console-web/src/styles/console-experience.css`、`console-web/src/styles/public-home.css`、`console-web/src/styles/identity-access.css` 和 `console-web/src/styles/identity.css` 的设计系统覆盖层；控制台 v3 追加了页面画布、导航轨、数据表面和 Gateway 三段式工作区。Chromium 截图复核首页和登录页桌面/移动视口，产物为 `.artifacts/ui-redesign-r1-*.png`；控制台角色审计生成了 `.artifacts/product-qa/20260930-console-r9/role-screenshots/`，运行器在 240 秒容量限制内超时，保留为未完成证据，不把部分截图改写为全路由通过。

本轮重设计面向中文首发的 MetaHub 控制台，目标是让组织管理、开发者接入和普通查看者都能在同一套视觉规则下快速找到下一步。业务 API、权限和数据模型保持不变。

## 视觉基线

- 页面背景使用暖灰绿，内容面使用白色，导航轨使用深墨绿，强调色使用青绿色；错误和警告只在状态需要时出现。
- 正文使用系统无衬线字体栈：Inter、Segoe UI、Microsoft YaHei、PingFang SC、Arial。
- 控件统一使用 6px 圆角；页面面板 10px；弹框 12px。阴影只用于弹框和导航轨。
- 间距采用 4px 基数：4、8、12、16、20、24、32px。
- 共享 token 位于 `console-web/src/styles/main.css` 的 `:root`，控制台最终覆盖位于 `console-web/src/styles/console-experience.css`。

## 信息架构

- 顶部栏只保留产品、当前身份、组织切换、账号设置和退出。
- 侧栏按角色返回业务域；同一时间只展开当前域，移动端默认收起。
- 组织管理员概览优先显示组织状态和核心指标；未完成首次接入时才显示配置引导。
- 开发者首页只显示 Gateway、个人 KEY、协议入口和个人用量；Provider、模型目录、路由和私有 Gateway 属于组织配置。
- 成员目录使用表格和分页，不把大量成员渲染成纵向卡片列表。

## 交互规则

侧栏分组使用单组手风琴。用户展开 Gateway 或其它业务大类后，当前组的全部已授权入口直接显示，其余组自动折叠；不再使用“更多控制”延迟菜单或组三项截断。

- 添加和编辑配置优先使用同一个弹框壳体，通过内部视图切换模式。模型路由当前使用 `data-model-alias-dialog`，Provider/API KEY 也使用独立弹框。
- 空表单和低频高级项默认收起；错误、成功和加载反馈显示在当前操作附近，不把用户滚动到页面顶部或底部找结果。
- 所有按钮、输入框、选择框和弹框使用同一焦点环、禁用态和圆角基线。
- 普通用户只看到业务名称、地址、状态、计价和可执行操作；内部 ID、请求号、迁移字段、认证代码和工程诊断保留在 API 或日志层。
- 2026-09-30 全仓动作入口审计：`console-web/src` 共 39 行锚点模板，5 行保留为首页返回、账号分区或引用来源；动作型内部入口均已改为按钮或控制台导航按钮，动作关键词匹配的内部锚点为 0。

## 响应式

- 桌面端使用可用视口宽度，侧栏和主内容按 `minmax(0, 1fr)` 收缩。
- 820px 以下侧栏收起，顶部操作允许换行，表格转为横向滚动或字段标签化的两列记录。
- 700px 以下弹框操作按纵向排列，按钮保持可触摸的最小高度。
- 公共首页和登录页在 1440px、390px 和 390x480 视口保持无横向溢出，首屏内容不依赖固定裁剪高度。
