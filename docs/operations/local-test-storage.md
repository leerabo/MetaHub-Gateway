# 本地测试空间控制

普通界面、文案和样式修改优先使用现有预览与针对性检查，不为此启动新的数据库、复制数据库或创建虚拟机。只有安装、迁移、备份恢复等确实依赖隔离数据的验收才使用相应环境。

生成安装包或验证可重复构建时，临时重复包在校验后立即删除；保留交付候选和小体积报告，避免按每次测试积累完整副本。需要保留的失败环境记录用途并复用，不因一次失败重新创建整套环境。

本地验收只复用 `.tmp/trial-ubuntu` 这一套 Ubuntu 虚拟机。已有磁盘时，初始化脚本拒绝再次配置；后续使用 `scripts/acceptance/resume-trial-linux.py`。

启动虚拟机、迁移导入测试、辅助 PostgreSQL 测试前，宿主机必须至少剩余 5 GiB。虚拟机启动后每 5 秒检查空间：剩余空间低于 5 GiB，或测试磁盘文件达到 20 GiB 时，只暂停本测试虚拟机并记录原因，不删除数据、不自动重试。

辅助 PostgreSQL 测试结束并确认服务停止后，自动删除本次创建的数据目录，保留报告与日志。迁移导入测试若已有保留集群，要求通过 `--resume-work` 明确复用，禁止继续新建重复集群。

清理旧测试数据前，必须确认路径位于本工作区 `.tmp` 内、不含符号链接或目录联接、没有进程使用、没有运行中的 PostgreSQL 标记。保留原业务数据库、密钥、发布安装包、截图、测试报告和失败日志。
