# 组织治理与系统入口

调用记录属于“治理”，平台支持和成员调用反馈属于导航底部的“系统”。这些入口服务于组织管理员的日常排查和改进，不负责配置模型、路由或成员。

## 调用记录

查看本组织成员通过 Gateway 发起的调用结果、实际使用的模型、故障切换、延迟、Token、成本、项目和应用归属。它回答的是“刚才这次调用发生了什么”，不是平台服务端的原始日志浏览器。

## 系统：成员调用反馈

统计本组织成员在调用详情中提交的评分、是否采纳和标签。没有成员提交反馈时显示“暂无数据”，不会把平台人员或其他组织的反馈混进来。

## 系统：平台支持

组织管理员遇到 MetaHub 平台问题时提交工单并查看处理进度。工单会发送到 MetaHub 平台支持队列；它不是组织内部成员之间的消息，也不是给组织成员发通知的工具。

## 迁移中心

迁移中心用于 SaaS 平台运维人员评估旧租户、私有部署或直连配置，并执行切换、检查和回退。组织管理员不需要使用它，因此不再出现在组织控制台导航中。

## 服务健康

服务健康用于平台级运行检查。组织首页已经展示组织可用性摘要，组织控制台不再提供重复的服务健康页面；平台运维仍可从平台侧查看完整健康状态。

## 调用记录不可用时

页面只显示可行动的重试提示，不显示 SQLite、触发器或内部会话字段。服务端日志会记录受限的数据库错误分类，用于区分锁竞争、会话归属约束和其他存储约束。

## 首页：审批中心

审批中心只处理需要组织管理员确认的预算阻断和高风险操作。没有待审批事项时显示空列表；它不负责模型路由、成员管理或平台支持。
