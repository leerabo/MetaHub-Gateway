# 控制台角色功能边界

本轮把“组织接入向导”和“日常工作台”分开。向导只负责首次配置，组织管理员完成配置后默认进入组织概览；旧的 `getting-started` 地址会自动回到概览。员工继续从“我的接入”查看统一 Gateway 地址和个人 KEY。

| 角色 | 默认入口 | 可见功能 | 不显示的功能 |
| --- | --- | --- | --- |
| SaaS 平台管理员 | 平台控制台 | 租户、部署、数据生命周期、平台运维 | 组织成员的日常接入页 |
| 组织所有者 / 组织管理员 | 组织概览 | 成员、角色权限、模型服务、模型、默认路由、预算、治理、用量和审计 | 平台部署环境、平台数据生命周期 |
| 开发者 | 开发者接入 | 统一 Gateway 接入信息、个人 KEY、API/SDK/MCP 接入说明、自己的用量 | Provider、模型目录、模型路由、本地模型、私有 Gateway、组织项目 |
| 员工 / 查看者 | 我的接入 | 统一 Gateway 地址、个人 KEY、个人用量 | 组织配置、Provider、模型、路由、财务和治理管理 |
| 财务管理员 | 财务工作台 | 用量、预算、额度、成本和财务例外 | 模型服务和平台部署配置 |
| 安全 / 审计角色 | 治理与观测 | 安全策略、审计和请求观测 | 模型服务写入、成员和平台部署写入 |

角色边界同时作用于默认入口、侧栏投影、URL 深链解析和控制面导航投影。开发者或查看者即使继承了较宽的历史权限，控制面也不会返回 Provider、模型、路由、本地模型或私有 Gateway 入口；旧 hash 会回到本角色首页。开发者直接打开组织配置地址时会返回开发者接入页，组织管理员访问遗留向导地址时会返回组织概览。

本轮验证：控制面角色导航集成 `7/7`，PRD-146 导航定向单测 `39/39`，接入与 KEY 定向回归 `68/68`，合并定向 Node 回归 `94/94`，lint `842 files`，生产构建 `295 assets`。这批验证不替代真实外部客户验收，PRD-148 仍保持未完成。
